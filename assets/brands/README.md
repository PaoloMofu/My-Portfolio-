# Brand logos (Behind the cuts — "Powered by")

Right now the Claude and Higgsfield marks in `index.html` are small **stylized
SVGs drawn inline** — close, but not the official logos.

To use the real ones:
1. Download the official SVGs from each brand's press/brand page
   (Anthropic/Claude brand assets; Higgsfield brand kit).
2. Save them here as `claude.svg` and `higgsfield.svg`.
3. Tell me and I'll swap the inline marks for `<img src="assets/brands/…">`.

Keep them monochrome/simple so they read at ~16px on the dark panel.
