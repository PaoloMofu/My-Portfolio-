# Video files

The **AI reels** section pulls the 3 YouTube Shorts directly (thumbnail + click-to-play
lightbox) — no local files needed. To change them, edit the `data-yt="<id>"` values on
the `.reel` buttons in `index.html` (`#work` section).

Local files are still used for two spots. Drop them here with these exact names:

| File           | Where it plays        | Aspect |
|----------------|-----------------------|--------|
| `showreel.mp4` | Hero timeline preview | 16:9   |
| `about.mp4`    | Behind the cuts panel | 4:5 / any |

Optional poster stills: `showreel-poster.jpg`, `about-poster.jpg`
Recommended: MP4 (H.264), muted, ~8–15s loop, 1080p or smaller.
